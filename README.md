# Пиксельное портфолио веб-дизайнера

Одностраничный сайт в стилистике пиксельной игры: персонаж сидит за компьютером на главном экране, а при скролле встаёт и прыгает по элементам страницы.

## Запуск
Открыть `index.html` в браузере — сборка не нужна.

## Структура
- `index.html` — разметка: главный экран, работы, обо мне, контакты
- `css/style.css` — стили
- `js/sprites.js` — пиксельные спрайты персонажа и иконок
- `js/app.js` — сцена, анимация печати, прыжки по платформам

Чтобы персонаж мог прыгать на новый блок, добавьте ему атрибут `data-platform`
(необязательно: `data-x="0.3"` — точка приземления по ширине блока).
